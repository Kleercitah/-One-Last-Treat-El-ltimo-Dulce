# Imagen de la dedicatoria

Coloca aquí tu archivo **imagen.png**, respetando minúsculas. No se ha creado una
imagen provisional. En desarrollo aparece al recargar; para publicar, vuelve a
ejecutar `npm run package:web` después de añadirla.

Los textos están en `src/config/creditsConfig.js`. La imagen usa `object-fit:
contain`: conserva proporciones, no se recorta y no tiene texto superpuesto.
